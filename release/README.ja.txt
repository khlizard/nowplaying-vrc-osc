DJ Now Playing for VRChat
（アプリ表示名: Now Playing → VRChat）
バージョン {{VERSION}}

================================================================================
概要
================================================================================

rekordbox で再生した曲の情報を、VRChat の Chatbox へ OSC で送る
非公式ツールです。rekordbox のデータベース（master.db）を読み取り専用で
直接読みます。Now Playing App は不要です（v2 から）。

  ※ rekordbox（AlphaTheta）および VRChat の公式ツールではありません。
  ※ master.db には書き込みません。
  ※ 自己責任でご利用ください。

================================================================================
動作環境
================================================================================

  OS      : Windows 10 / 11（64bit）
  .NET    : 不要（アプリに同梱されています）
  その他  : rekordbox 7、VRChat（OSC 有効）
  通信    : 初回の復号キー取得と、Spotify 曲の曲名取得でインターネットを使います

================================================================================
必要なソフト
================================================================================

  1. rekordbox 7

  2. VRChat
     アクションメニュー → Osc → Enabled をオンにしてください。

================================================================================
使い方
================================================================================

  1. ZIP を解凍します。
     フォルダ内のファイルをバラバラに移さず、フォルダごと任意の場所に置いて
     ください。

  2. NowPlayingVrcOsc.exe をダブルクリックして起動します。

  3. ウィンドウの［開始］を押すと rekordbox の監視が始まります。

  4. rekordbox が履歴に曲を記録したタイミングで VRChat Chatbox に送信されます。
     （起動時に再生中の曲は送信しません）

     rekordbox は「再生時間設定」（環境設定 > 詳細 > ブラウズ）の秒数だけ
     再生してから履歴に記録します。送信はその分遅れます。
     デッキの情報は取れないため、最後に記録された曲を送信します。

     Spotify の曲は、曲名だけを Spotify から取得して送信します
     （アーティストは送信しません）。

  5. ［テスト送信］で VRChat への疎通を確認できます。

  6. ウィンドウを最小化するとトレイに格納されます。
     トレイアイコンをダブルクリック（または右クリック →「ウィンドウを表示」）で
     ウィンドウを再表示できます。

  7. ウィンドウの × を押すとアプリを終了します。
     トレイから終了する場合は、トレイアイコン右クリック →「終了」。

================================================================================
初回起動時の SmartScreen について
================================================================================

  コード署名のない exe のため、Windows が「PC が保護されました」と表示する
  場合があります。

  1. 「詳細情報」をクリック
  2. 「実行」をクリック

  信頼できる配布元から入手した場合のみ実行してください。

================================================================================
設定
================================================================================

  ［設定...］から変更できます。内容は次に保存されます:

    %AppData%\NowPlayingVrcOsc\settings.json

  主な設定:
    - master.db の場所（空欄なら自動検出）
    - 復号キー（自動取得できないときだけ入力）
    - VRChat OSC 送信先（既定: 127.0.0.1:9000）
    - Chatbox メッセージ: ヘッダ、区切り文字、表示項目（曲名・アーティスト等）

  master.db の復号キーは自動で取得し、Windows の機能（DPAPI）で暗号化して
  次に保存します:

    %AppData%\NowPlayingVrcOsc\key.dpapi
