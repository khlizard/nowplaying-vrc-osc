DJ Now Playing for VRChat
（アプリ表示名: Now Playing → VRChat）
バージョン {{VERSION}}

================================================================================
概要
================================================================================

Now Playing App 2 (NP2) から再生中の曲情報を取得し、VRChat の Chatbox へ
OSC で送る非公式ブリッジです。

  ※ Now Playing App および VRChat の公式ツールではありません。
  ※ 自己責任でご利用ください。

================================================================================
動作環境
================================================================================

  OS      : Windows 10 / 11（64bit）
  .NET    : 不要（アプリに同梱されています）
  その他  : Now Playing App 2、VRChat（OSC 有効）

================================================================================
必要なソフト
================================================================================

  1. Now Playing App 2
     https://nowplayingapp.com

  2. VRChat
     アクションメニュー → Osc → Enabled をオンにしてください。

================================================================================
使い方
================================================================================

  1. ZIP を解凍します。
     フォルダ内のファイルをバラバラに移さず、フォルダごと任意の場所に置いて
     ください。

  2. NowPlayingVrcOsc.exe をダブルクリックして起動します。

  3. ウィンドウの［開始］を押すと NP2 の監視が始まります。

  4. 曲が切り替わったタイミングで VRChat Chatbox に送信されます。
     （起動時に再生中の曲は送信しません）

  5. ［テスト送信］で VRChat への疎通を確認できます。

  6. ウィンドウを最小化するとトレイに格納されます。
     トレイアイコンをダブルクリック（または右クリック →「ウィンドウを表示」）で
     ウィンドウを再表示できます。

  7. ウィンドウの × を押すとアプリを終了します。
     トレイから終了する場合は、トレイアイコン右クリック →「終了」。

================================================================================
初回起動時の SmartScreen について
================================================================================

  コード署名のない exe のため、Windows が「PC が保護されました」と表示する
  場合があります。

  1. 「詳細情報」をクリック
  2. 「実行」をクリック

  信頼できる配布元から入手した場合のみ実行してください。

================================================================================
設定
================================================================================

  ［設定...］から変更できます。内容は次に保存されます:

    %AppData%\NowPlayingVrcOsc\settings.json

  主な設定:
    - 取得方式: auto（既定）/ config / socketio
    - NP2 config.json のパス
    - VRChat OSC 送信先（既定: 127.0.0.1:9000）

================================================================================
トラブルシューティング
================================================================================

  症状                    確認すること
  --------------------------------------------------------------------------
  曲が更新されない        NP2 が起動しているか。DJ ソフトで曲が変わっているか
  VRChat に表示されない   OSC が有効か。［テスト送信］を試す
  config が読めない       %USERPROFILE%\.nowplaying\config.json の存在
  ポート不一致            config.json の localSocketPort を確認
